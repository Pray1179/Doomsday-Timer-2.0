# Character Catalogue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 30-person Doomsday cast page with a comprehensive, image-rich, data-first on-screen Marvel character catalogue (~250+ records, real per-character static pages) that scales to arbitrary size.

**Architecture:** New standalone subsystem — batched data in `data/catalogue/*.json` merged into a validated `data/catalogue.json`, generated by `scripts/build_catalogue.py` into `explore/characters.html` (the replaced catalogue listing) plus `explore/catalogue/<id>.html` detail pages and SVG emblems. `build_explore.build_all()` hands off `characters.html` to `build_catalogue` last (exact precedent: `build_mcu` already overwrites the timeline), so the site determinism + link-crawl tests cover the final page. Existing `data/cast.json`, `pages/<slug>.html`, and the 30-count semantics stay intact; catalogue records cross-link to the 30 via `doomsday_cast_slug`.

**Tech Stack:** Python 3 stdlib only (json, re, pathlib, hashlib, collections.Counter); static HTML + existing CSS; plain JS for filters. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-08-30-character-catalogue-design.md` (approved). The plan argues from the spec; executors read both.

## Global Constraints

- **Do not** edit `HackClaude_Project_Brief.md` or unrelated HackClaude reference files. Scope is `avengers-doomsday/`.
- **Do not** modify `data/cast.json`, `scripts/build.py`, `scripts/build_mcu.py`, `index.html`'s existing sections, or `assets/js/main.js`'s existing functions. Only additive edits + the `build_explore.build_all()` handoff line.
- Existing three suites must keep passing: `test_site.py`, `test_explore.py`, `test_knowledge.py`.
- Deterministic output: no timestamps, random, or build-time `datetime` in generated artifacts.
- Preserve the dark cinematic green/teal design system (`--bg #020804`, `--surface #0a1a10`).
- Every `image_url` must be `https://`, have `image_alt`, `image_source_url`, `image_source_name`. Unverified ⇒ SVG fallback + "Image pending verification" chip. Never a broken image icon.
- Variants are separate records. Do not merge the three live-action Peter Parkers, main Loki vs TVA/variant Lokis, or main Gamora vs the 2014 variant.
- Uncertain continuity/identity ⇒ `verified:false` + `source_notes`/`notes`, clearly separated from confirmed canon.
- No git commits exist in this repo yet; commit only if the user explicitly asks to start tracking.

**Interfaces:**
- `catalogue_util.load_all() -> list[dict]` — reads every `data/catalogue/*.json` (each a `{"characters":[...]}`), concatenates in sorted filename order, returns `list[dict]`.
- `catalogue_util.slug_ok(s: str) -> bool` — `^[a-z0-9]+(?:-[a-z0-9]+)*$`.

- `catalogue_util.initial_portrait(name, color) -> str` — deterministic SVG monogram (same look as `build_explore._emblem_svg`).
- `catalogue_util.CONTINUITY_COLORS: dict[str,str]` — keyed by `continuity`, used for portrait ring color.
- `catalogue_util.REQUIRED: frozenset[str]` — `{"id","name","alias","universe","continuity","team_or_affiliation","status","debut_title","source_notes","related_titles","verified"}`.
