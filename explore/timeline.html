Release Timeline (40)

The main timeline below is the MCU THEATRICAL RELEASE ORDER (2008 → 2026), the view Marvel/Disney uses in its public timeline and the one that best shows how the saga unfolded. It is NOT in-universe chronology — in-universe set-dates differ (e.g. Captain Marvel is set in 1995 but released 2019). Where a title's in-universe placement is important it is noted. Phases and Sagas describe release-program grouping.
